# salestongue

**给小商家的销售话术包生成器** — 输入产品和行业，一条命令生成一整套能直接用的话术：
3 条短视频脚本、直播开场与逼单话术、客户常见问答、首图海报文案。

*Sales-talk kits for small merchants: short-video scripts, livestream talk
tracks, customer Q&A and poster lines — generated offline from industry
packs. No API key, no credits, no upload.*

```bash
pip install -e .
salestongue packs
salestongue make --industry fabric --product 库存棉布 \
    --brand 晓威库存布 --slogan 买库存布找晓威库存布 \
    --price "3元/米起" --points 现货多,花色全,价格低 --out kit.md
```

生成的话术包长这样（节选）：

```text
### 脚本2：镜头直接进仓库，一卷一卷全是实拍
- 开场钩子：库存棉布刚拉回仓库，上一批三天就卖空了
- 镜头直接进仓库，一卷一卷全是实拍，颜色、克重当面验给你看
- 卖点：花色全，库存棉布都是实拍实测，不玩虚的。
- 价格：3元/米起，这个价只在晓威库存布。
- 结尾引导：想要的老板点关注私信我，买库存布找晓威库存布
```

## 为什么做这个

2026 年卖家 AI 工具一片红海，但都在卷同一件事：英文界面、按积分收费、
把产品图生成视频。而中国千千万万个批发小商家（卖布的、卖家具的、
卖服装的）真正的门槛不在剪辑，在**开口**：拍视频不知道说什么、
开直播冷场、客户问的问题答得磕磕巴巴。

话术是这个生意的真瓶颈。salestongue 把每个行业里验证过的话术结构
（钩子—信任—卖点—价格—引导）做成行业包，商家填自己的产品和口号，
一分钟拿到整套成品。离线运行、结果可复现（换 `--seed` 换一批），
话术包像代码一样可以存档、比较、迭代。

## 行业包

| pack | 行业 | 内容 |
|---|---|---|
| `fabric` | 面料/库存布 | 仓库实拍、验布、大厂余料叙事、寄样问答 |
| `furniture` | 家具/沙发 | 工厂直营、拆架验料、户型尺寸、售后保修 |
| `clothing` | 服装 | 上身实穿、版型尺码、运费险退换 |
| `general` | 通用百货 | 实测演示、源头渠道、七天无理由 |

每个包包含：开场钩子、信任角度、结尾引导、直播开场、直播逼单、
5+ 组客户问答、海报文案 — 全部带 `{产品/品牌/口号/价格/卖点}` 占位。

## 商业模式

核心引擎 MIT 开源免费。话术的价值在**包**，不在代码：

- **行业包买断** ¥99/个：深度行业话术包（更细的品类、更多问答、
  节日促销专题）
- **订阅** ¥29/月：每月新行业包 + 现有包话术更新 + 优先新增行业投票
- **定制包** ¥999/个起：按你的店、你的产品、你的口头禅做专属包

## 路线图

- LLM 润色模式（可选）：把话术包按你的语气再加工，需自备 API Key
- 短视频成片流水线：话术包 → 配音/字幕/口号结尾卡，自动出 MP4
- 更多行业包：五金、食品、汽配、美妆……
- 微信小程序版：手机上填一填就能生成
